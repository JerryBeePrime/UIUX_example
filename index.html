BONUS MISSION

🆚 Bootstrap 比一比

兩邊是完全相同的 HTML，唯一差別是右邊多載入了一行 Bootstrap 的 CSS。

🧑‍🏫
「不用自己寫一堆 CSS，加一行就有現成的按鈕、卡片、表格和版面格線！」

❌ 沒有 Bootstrap（瀏覽器預設樣式）

✅ 有 Bootstrap 5.3.8

差別只在這一行（放在 <head> 裡）：

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

Bootstrap 幫你做了什麼？

  • 重設與排版：統一字體、行距、邊距。
  • 元件：.btn、.card、.alert、.navbar 加上 class 就有樣式。
  • 表單與表格：.form-control、.table-striped 讓欄位與表格立刻整齊。
  • 格線系統：.row + .col-4 把內容分成三等分欄位。

💡 兩個範例放在 iframe 裡，因為 Bootstrap 的 CSS 是全域的，直接放進本頁會蓋掉漫畫主題。需要網路才能載入 Bootstrap。
